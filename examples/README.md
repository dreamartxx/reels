# Örnekler

`turkce-ornek.mp3`, macOS Yelda sesiyle üretilmiş kısa bir Türkçe test kaydıdır. Referans metni `siir.txt` dosyasındadır. Yerel kurulumun “Türkçe örnekle dene” düğmesi bu kaydı kullanır.

Kullanıcıların özel şiirleri, sesleri, zamanlama sonuçları ve MP4 çıktıları GitHub'a dahil edilmez. Gerçek dosya ile test etmek için kendi kayıtlarınızı bu klasöre koyun; `.gitignore` özel örnekleri korur.
